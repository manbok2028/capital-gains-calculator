# 양도소득세 계산기 (주택)

세무사 사무소에서 고객이 직접 쓰는 것을 목표로 만든 양도소득세 콘솔 계산기입니다.
세율과 공제 같은 법령 수치는 코드가 아니라 `rules_2026.json`에 모아 두었고,
모든 세액 계산은 `float` 없이 정수와 분수로 합니다.

## 자동 계산 범위 (1차)

- 국내 주택 1채를 **매매로 취득**해 양도하는 경우
- 1세대 1주택 비과세 판정 (보유 2년, 조정대상지역 취득 시 거주 2년, 12억 초과 고가주택)
- **일시적 2주택 비과세 특례** 판정 (소득세법 시행령 제155조 제1항, 2026.10.1. 시행 개정 반영)
- **동거봉양 합가·혼인 합가 비과세 특례** 판정 (같은 영 제155조 제4항, 제5항)
- 일반 과세 (기본세율 6~45%, 단기보유 1년 미만 70% / 2년 미만 60%)
- 장기보유특별공제(표1, 표2), 기본공제, 지방소득세

**범위 밖은 계산하지 않고 상담을 안내합니다.** 세대 보유 주택이 3채 이상, 일시적 2주택 요건을 충족하지 못한 2주택
(다주택 중과 검토 필요), 상속·증여로 취득한 주택, 분양권·입주권 등입니다.

## 실행 방법

```
python3 main.py
```

- 메뉴 1: 질문에 답하면 비과세 판정과 세액을 계산합니다. (날짜 `2018-05-10`, 금액 `13억5000만` 등)
- 메뉴 2: `cases.json`의 검증용 사건을 모두 계산해 PASS/FAIL을 보여 줍니다.

테스트:

```
python3 test_core.py
python3 test_inputs.py
python3 test_exemption.py
python3 test_tax_base.py
python3 test_temporary_two.py
python3 test_merged_household.py
python3 run_cases.py
```

## 계산 순서

1. 입력 검증: 날짜, 금액 형식, 양도일 > 취득일, 거주기간이 보유기간 안에 있는지 (`inputs.py`)
2. 비과세 판정 (`exemption.py`): 비과세 / 고가주택 일부 과세 / 과세 / 상담 필요
3. 양도차익 = 양도가액 − 취득가액 − 필요경비. 고가주택은 `(양도가액 − 12억) / 양도가액` 비율만 과세
4. 장기보유특별공제 (`tax_base.py`): 1세대 1주택이고 보유 3년 이상, 거주 2년 이상이면 표2(보유 연 4% + 거주 연 4%, 최대 80%), 그 밖에는 표1(보유 3년 이상부터 연 2%, 최대 30%)
5. 양도소득금액 − 기본공제(연 250만원) = 과세표준
6. 세율 적용 (`calculator.py`): 기본세율은 `과세표준 × 세율 − 누진공제`, 단기보유는 단일 세율
7. 지방소득세 = 산출세액 × 10%

## 일시적 2주택 비과세 특례

종전주택(양도하는 주택)을 취득하고 **1년이 지난 후** 신규주택을 취득해 일시적으로 2주택이 된 1세대가
**신규주택 취득일부터 N년 이내**에 종전주택을 양도하면 종전주택을 1세대 1주택으로 보아 판정합니다. (`temporary_two.py`)

| 구분 | 처분기한 |
|---|---|
| 신규주택 취득일 현재 종전주택이 조정대상지역에 있고, 신규주택도 조정대상지역에 있으며, 신규주택(또는 계약금 지급)이 2026.8.4. 이후이고, 종전주택 양도가 2026.10.1. 이후 | 2년 |
| 그 밖의 경우 (계약금을 2026.8.3. 이전에 지급한 경우, 조정대상지역 공고일 이전 취득, 한쪽이 조정대상지역이 아닌 경우 등) | 3년 |

- 요건: 신규주택 취득 직전 세대 보유 주택 1채, 종전주택 취득 후 1년 경과(취득일 1년 후 같은 날은 아직 아님, 다음 날부터), 처분기한 이내 양도
- 특례를 적용받는 종전주택은 1세대 1주택 비과세 요건(보유 2년, 조정대상지역 취득 시 거주 2년)도 갖춰야 하고,
  12억 초과분은 과세, 장기보유특별공제는 표2 적용 가능
- 요건을 못 채우거나, 특례 요건은 맞지만 종전주택이 비과세 요건을 못 채우면 2주택자 양도(조정대상지역 중과 등)로 보고 **상담 필요**로 안내
- 근거: 소득세법 시행령 제155조 제1항 (대통령령 제36737호, 2026.9.30. 공포, 2026.10.1. 시행)과 부칙 제2조

## 동거봉양 합가·혼인 합가 비과세 특례

양쪽 세대가 각각 1주택씩 보유하다가 세대를 합쳐 2주택이 된 경우, **합친 날(혼인한 날)부터 10년 이내에 먼저 양도하는 주택**을
1세대 1주택으로 봅니다. (`merged_household.py`)

- 동거봉양 합가: 합가 당시 60세 이상(또는 법령이 정한 요건에 해당하는) 직계존속(배우자의 직계존속 포함)이 있어야 하고,
  합가 전에 실제로 별도 세대였어야 합니다. (실제 별도 세대 여부는 사실판단 사항)
- 혼인 합가: 혼인 직전 양쪽이 각각 1주택씩이어야 하며, 한쪽이 다주택이면 특례를 적용받지 못합니다.
- 양도하는 주택은 합가(혼인) 당시 이미 보유한 주택이어야 하고, 1세대 1주택 비과세 요건(보유 2년 등)도 갖춰야 합니다.
- 10년은 2024.11.12. 이후 양도분 기준입니다(혼인 합가는 그 전에는 5년). **1차 구현은 2024.11.12. 이후 양도분만 자동 판정하고
  그 전 양도분은 상담으로 안내**합니다.
- 요건에 대한 입력이 없으면 충족하지 못한 것으로 보아 상담으로 안내합니다. (안전한 쪽으로 판단)

## 검증 방법

- `core.py`: 누진세를 "공식(누진공제)"과 "구간별 합산" 두 방식으로 계산해, 모든 구간 경계와 무작위 5,000건에서 일치함을 확인
- `cases.json`: 35개 사건(일반 과세 12건 + 일시적 2주택 12건 + 합가 특례 11건)의 기대값을 **손계산으로** 구해 두고 프로그램 결과와 비교
  (비과세, 고가주택, 단기보유, 양도차손, 상담 필요, 입력 오류 포함)
- `test_temporary_two.py`: 2년/3년 규정 구분, 계약금 경과조치, 공고일 예외, 1년 경과 경계, 처분기한 경계
- `test_merged_household.py`: 10년 기한 경계(마지막 날/하루 초과), 요건 누락, 시행 시점(2024-11-12) 경계
- 경계값: 12억 정확히 / 1원 초과, 보유 2년 전날 / 당일, 조정대상지역 취득일 2017-08-02 / 08-03, 공제율 표 경계

## 법령 기준과 확인이 필요한 지점

기준: 2026년 양도분 현행법. 2026 세제개편안(장기거주 소득공제 전환 등, 2028년 이후 시행 예정)은 확정 전이라 반영하지 않았습니다.
법령이 바뀌면 `rules_2026.json`을 연도별로 새로 만들어 교체합니다.

| 항목 | 위치 | 비고 |
|---|---|---|
| 보유기간 "N년 이상" 기산 기준 | `inputs.py`의 `PERIOD_RULE` | 응당일 당일 충족 / 다음 날부터 충족 중 선택, 하루 차이로 판정이 갈릴 수 있음 |
| 조정대상지역 거주요건 적용 취득일 | `exemption.py`의 `RESIDENCE_REQ_FROM` (2017-08-03) | 소득세법 시행령 제154조 원문 대조 필요 |
| 원 미만 절사 시점 | `tax_base.py`의 `floor_won` | 단계마다 절사, 10원 단위 절사 여부 등 실무 기준 확인 필요 |
| 세율표·공제율·12억 기준 | `rules_2026.json` | 소득세법 제89조, 제95조, 제104조 대조 필요 |
| 일시적 2주택 처분기한(3년/2년), 시행 기준일 | `rules_2026.json`의 `temporary_two_house` | 시행령 제155조 제1항, 부칙 제2조 대조 |
| 처분기한을 "응당일 당일까지"로 계산 | `temporary_two.py`의 `check_temporary_two_house` | 민법상 초일불산입 기준으로 구현, 실무 기준 확인 필요 |
| 합가 특례 10년 기한을 "응당일 당일까지"로 계산, 2024-11-12 이후 양도분만 자동 판정 | `merged_household.py`, `rules_2026.json`의 `merged_household` | 시행령 제155조 제4항, 제5항 대조, 처분기한 기산은 실무 기준 확인 필요 |
| "조정대상지역" 판정 시점 | 고객 입력(신규주택 취득일 현재) | 종전·신규주택 모두 취득일 현재 소재지를 묻는 방식 |

## 한계

- "1세대" 판단(배우자, 세대 분리, 동거봉양 합가 등)은 고객이 입력한 주택 수를 그대로 사용합니다.
- 다주택 중과, 상속·증여 취득, 분양권·입주권, 상생임대·임대사업자 특례, 무주택자의 동거봉양 후 혼인 같은 복합 합가는 자동 계산하지 않습니다.
- 일시적 2주택에서 신규주택의 "조정대상지역 공고일"은 고객이 알려주는 경우에만 반영합니다.
- 거주기간은 한 구간만 입력받습니다.
- 계산 결과는 참고용이며 신고 전 세무사 확인이 필요합니다.
